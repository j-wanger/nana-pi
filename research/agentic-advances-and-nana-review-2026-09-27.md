Flow theory *predicts* "autonomy up, consistency flat" from this shape; the causal link to the September voids is inferred, not measured. 4. **Context is stale, not bloated.** Session-start payload is 4–6k tokens (fine). The-hive's `.pi/handoff.md` is a 09-13 compaction summary ("do not modify gameplay code yet") re-injected into every the-hive pi session since: 56 pickups since 09-16 (143 pickups globally) **(seat-verified: file date; global count)**. 151 of 228 knowledge pulls point at monthly session archives **(seat-verified)**; downstream use is unmeasured (a citation proxy found 0, but the proxy misses in-session reads).
5. **The pi gate misses common destructive forms and can be turned off by the agent it gates** **(seat-verified by re-running the probes)**: `rm -r -f`, `find -delete`, `git clean --force`, `git push origin +main`, `rsync --delete` pass; an allow-pattern short-circuits `git status; rm -rf ~`; a write to `~/.pi/agent/nana-pack.json` is allowed; a malformed config silently drops `extraPatterns`; an untrusted repo's `.pi/handoff.md` is injected. **And the trust check would not have helped: pi 0.84.4 auto-trusts a repo whose `.pi/` holds only nana files** (`trust-manager.js`: a bare `.pi` with `nana-pack.json` + `handoff.md` has no trust-requiring resource), so a cloned repo's `.pi/nana-pack.json` post-edit commands already run on the first edit with no prompt, and its `gate.allowPatterns` are honored (Opus architecture pass F1, PRIMARY from pi source; the C4 probe had stubbed `isProjectTrusted → false`, which real pi never returns for that shape). It is documented as advisory, which bounds the *guarantee*, not the damage: only the sandbox/container bounds execution. Exposure today is low because builders are isolated `claude -p` workers, not pi.
6. **Decision models (Jev/Laya) earn no runtime ownership in nana yet.** Tool-result keep/drop is closed (local rounds 3–4 failed; independent replay puts Laya at AUROC 0.45–0.47 vs trivial rules 0.55–0.62). One reversible experiment is defensible later: a shadow-only local reranker behind the BM25 pull, gated on recall@3, irrelevant-hit rate and p95 latency together, after the pull's baseline is measured.
7. **External evidence supports nana's shape** (seat briefs, different-lineage reviewers that do not edit the artifact, lean contract specs, deterministic gates) and offers three cheap trials nana has not run: `claude -p --max-budget-usd` **(seat-verified: the flag exists; behavior untested)**, `/goal` (completion judged by a separate model from the transcript only), and pi 0.87's actionable turn-end, which needs an upgrade from the installed 0.84.4 **(seat-verified)** and a desk-parser compatibility check.
