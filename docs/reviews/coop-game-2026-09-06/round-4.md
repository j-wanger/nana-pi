### A — Fold check

**FINDING (severity: major):** Reduced-depth pushing, liquid ordering, move directions, start-view ablation, and decision depth were folded; step-up replaces no-jump but remains softened by “Jake may veto,” and symmetry remains underspecified. Most importantly, §3.3 does not imply §3.6’s consistency claim: in collapsed-X view, let the mover’s true destination `(0,1,1)` be solid while the front-most cell at that projected destination `(2,1,1)` is liquid. Step 1 sees the front-most liquid as non-solid, steps 2–3 find no entity, and step 4 moves the entity into the hidden true solid. The same defect applies to a pushed box. Thus checking the projected front-most cell is not checking the true destination, so re-embedding is not vacuous as written.

### B — Totality and determinism

**FINDING (severity: blocker):** The transition remains partial or contradictory in several requested cases. A pushed box whose true destination is hidden solid behind a front-most liquid is moved into solid. If the front-most cell is solid but the mover’s true destination is liquid, step-up moves it to the cell above the liquid and the vertical pass can immediately drop it into that liquid, creating a remote “stair” with no true support. If that true destination instead contains a box while a solid exists only at another depth, the step-up clause bypasses pushing and places the player above the box, conflicting with “a box is never stepped onto.” “Above” is also undefined for gravity along ±X or ±Z. Two against-gravity movers cannot actually contend because translation by one fixed vector is injective, and gravity-off liquid correctly yields no intent. Fragility is still contradictory: with a player on a box on a fragile cell, the box is supported and therefore has no “unsupported” gravity intent, so the fragile cell never breaks; allowing an attempted blocked gravity step instead makes it break and leaves the player’s subsequent support/fall timing dependent on an unstated snapshot rule.

### C — Solver

**FINDING (severity: blocker):** The canonical state space is finite, so visited-state BFS terminates, but it is not exact while the transitions above lack unique invariant-preserving successors. Starting in 3D for an ablated start view is sound for reachability because switches take no time and 3D was already reachable immediately from every start view; it cannot add a capability unavailable after ablation. The symmetry action is not closed as written, however: the full grid rotation/reflection group maps the sole top view through a Y reflection to a nonexistent bottom view, and rotations about horizontal axes likewise leave the stated view set. Restricting normalization to the vertical-axis dihedral group would correctly permute all four side facings under 90° rotations and reflections, but v4 does not state that restriction.

### D — Smallest playable

**PASS:** The first fixture is a valid reduced-depth legality fixture: its `+Z` move must be blocked by the box at another depth, although room bounds and an alternate route must be supplied to make it a complete solvable puzzle. Add a second “false stair” fixture with gravity `−Y`, side view from `+X`, player `(0,1,0)`, liquid true destination `(0,1,1)`, remote front-most solid `(2,1,1)`, and free cells `(0,2,0)` and `(0,2,1)`. A `+Z` action currently steps the player to `(0,2,1)` and then drops it to `(0,1,1)` in the same tick, jointly exercising step-up and the vertical pass and pinning the intended resolution once the true-destination rule is repaired.

VERDICT: BLOCK — The projected-cell check still permits entities inside true solids, while step-up, fragile support, and the overbroad symmetry group prevent an exact deterministic solver.
