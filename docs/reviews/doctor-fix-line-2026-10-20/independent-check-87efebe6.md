Known bugs:
- A (known bug, not MUST): on the win32 copy path, an unreadable regular file throws a non-SetupError inside the dry run. That file can be a rule copy, a skill mirror file or a PATH shim. runDoctor lets the error through, as its design says, so a stack trace replaces the summary line main used to print. The rows and exit 1 stay. No POSIX path to this crash was found: the POSIX dry run uses lstat, readlink and existsSync, and the settings read raises SetupError. On native Windows it needs a file whose read is denied or locked. Main's `install --dry-run` crashes the same way. Fix when next touched: catch any dry-run error and print a "could not predict" line instead of the trace.
- B (known bug): when `.claude` is a symlink, install refuses every skill, so the summary sends those skills to "fix by hand as each ✗ line says". Those ✗ lines tell the user to run install, which will not fix them. The plan's known limits cover ✗ lines that name no fix, not lines that name the wrong one. Main's line was no better ("run: nana-setup install" for all 33).
