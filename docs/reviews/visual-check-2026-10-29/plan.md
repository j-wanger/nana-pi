## Threat model

Honest variation in our tools' output is in scope: the judge numbering with `1)` or `1.`, PASS, FAIL or UNJUDGED in mixed case, a preamble before the list, a verdict reworded or missing, a spec line skipped or cited twice, a page still drawing when the shot is taken, a reference folder holding non-image files, an answer that judges style instead of quality. Deliberate forgery is out: a page drawn to fool the judge, text in a screenshot that tells it to pass, or a seat that edits `reader.md` before reading it. The prompt still tells the judge to treat images and spec as evidence, not instructions; a forged pass is a residual. The child also sees the account email Claude Code attaches by itself; that is a residual, not repo context.
