Amendments:
1. R-2180 now adds "and the JavaScript lookup succeeds". Without it, a link loop counts as an existing path and R-2180 conflicts with R-2181.
2. R-2181 is narrowed to a link loop, which is the only case its test builds.
3. R-2182 to R-2184 are narrowed to the case the test injects (EISDIR, "every path that resolves inside the checkout", "a home that install set up under that failure"). They were wider than their tests. R-2180 still covers the other codes.
4. The committed fixture and the two environment variables are gone. The setup test writes its preload into its temp root at run time, with the root and the code written in, as doctor-fix-line.test.mjs does. That is one file fewer and one definition of each value.
5. The preconditions FAIL the check, never skip it: the preload fires, install exits 0 under the failure, and the control is healthy. R-2181 first asserts that both lookups refuse the loop.
6. W3 becomes "fall back only on EISDIR", the narrow fix vite's prior art invites. Only R-2180 catches it.
7. Known limits now say outright that on such a volume a non-LAND verdict recorded through another spelling goes unseen. They also list what still uses the native lookup only: pi-worker on win32, the mutation runner, install-check and the adoption store key.
