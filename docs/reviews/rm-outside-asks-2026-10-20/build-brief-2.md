## Why
The independent check on build 1 (3d8e2d22) found a MUST. On macOS a plain `rm -f /tmp/x` now blocks headless, where main runs it. The new rule's temp roots come only from `acceptedTempRoots`, which on macOS is the OS temp folder under `/var/folders/…/T`, so `/tmp` and `/private/tmp` count as outside. `laneWriteHit` keeps `/tmp` as its own rule on macOS and Linux (`nana-gate.ts`, the `allowed` list), and `lib/gate-temp-roots.ts` says the caller keeps it; `commandHit` does not. A replay of 332 recorded rm calls blocks 73 more reviewer calls than main (67 `/tmp/…`, 5 `/private/tmp/…`, 1 `/config`). pi-review runs headless, so each is a block, and a compound call loses its whole command. The plan's own replay expected 1, not 73.

The seat's pairs on build 1 (`seat-mutate-output-3d8e2d22.txt`): 27 of 30 red. Three survive because no handler check reaches them: G2 (no outside check over the detection segments of an unsegmentable command), G5 (the working folder passed as home), G6 (every command told it is segmentable).
