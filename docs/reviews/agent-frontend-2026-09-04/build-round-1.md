**A1 — FINDING (BLOCKING).** The ledger tooth is bypassable. Both replay and live reducers accept any block having an `id` and any object-valued `produced_by`; neither calls `validateBlock` nor verifies the stamp against the enclosing tool event (`packages/nana-stage/lib/blocks.mjs:181-194`). Consequently another extension can append an arbitrary `nana-block` entry, or a later `tool_result` handler can inject a carrier with `{produced_by:{}}`, and it renders without passing `processToolResult`. The promised “second extension after nana-stage cannot reach the stage” protection and test do not exist; the current manifest merely avoids that ordering (`packages/nana-stage/extensions/nana-stage.ts:21-34`, `~/.pi/agent/apps/basketball.json:5-8`).

**A2 — FINDING (MINOR).** Mutating isolation is sound for normal browser requests: Node normalizes header-name casing, `Origin: null` and foreign origins are rejected, chunked bodies are detected through `transfer-encoding`, and every mutable route checks before `readBody` (`apps/desk/server.mjs:991-1003`, `apps/desk/apps.mjs:164-175,198-208`). HEAD/OPTIONS bypass the check but match no mutable route. However every cross-origin GET physically reaches its target: on 7317 this includes sessions, transcript, live, picker polling, resources, settings, context files, agents, child events and child files; on another app port it includes static files, manifest, session, events and entries. SOP prevents reading responses, but `/api/events` still briefly attaches to another child and retries as EventSource, so “app pages cannot reach another child” is overstated (`apps/desk/apps.mjs:185-197`). Origin host/scheme comparison is also case-sensitive, producing harmless false rejections for equivalent casing.

**A3 — FINDING (BLOCKING).** Spawn inputs are manifest-derived and the live manifest’s `-t`, `-na`, `--no-extensions`, and ordered `-e` flags agree with Pi’s documented semantics (`apps/desk/apps.mjs:125-145`, `apps/desk/server.mjs:126-158`; `docs/usage.md` Tool/Resource/Project Trust options). Two lifecycle holes remain. First, an empty or omitted manifest `tools` becomes `[]`, but `spawnChild` then omits `-t`, restoring all default tools—including bash/edit/write (`apps/desk/apps.mjs:66-72`, `apps/desk/server.mjs:136-138`). Second, concurrent `POST /api/session` requests can both observe no live child, spawn two children, overwrite `app.childId`, race on the same PID-scoped temp manifest, and orphan one process (`apps/desk/apps.mjs:174-181`, `apps/desk/apps.mjs:76-84,125-145`). Child exit during `get_state` is merely logged, leaving stale write-back rather than a reliable reattach record.

**A4 — FINDING (BLOCKING).** Collapsed-drawer, reload, multiple-dialog, and pre-stream arrival behavior otherwise hold because dialogs are stored server-side and replayed in `desk_hello` (`apps/desk/server.mjs:239-250`, `apps/desk/apps.mjs:185-197`). But answering a gate removes it immediately without awaiting or checking `/api/ui-response`; a network failure, 409, or child race leaves the dialog pending server-side while the only gate surface is hidden until reload (`apps/desk/public/stage/stage.js:196-205`). Timed dialogs also remain indefinitely in `child.dialogs` after Pi auto-resolves them, and child exit clears the server map without telling the page to dismiss existing gate cards (`apps/desk/server.mjs:216-235,1027-1040`). Thus the bar is neither reliably pending nor reliably truthful.

**A5 — FINDING (MAJOR).** On-screen provenance is not honest enough. The weak stamp checks from A1 allow forged provenance, while replay puts every message entry—including abandoned branches—into the drawer even though blocks are reduced only over the active leaf, so stale branch text can appear as the current “agent’s reading” (`apps/desk/public/stage/stage.js:269-277`). More fundamentally, `board_table` presents generated Markdown reports as data with only a filename/mtime scope, and `player_card` promotes dossier prose such as `history`, `trend`, and `rationale` into fields labelled by a tool stamp (`basketball-geek/src/basketball_geek/blocks.py:27,111-130,194-215,239-262`). Those are analyst/model-derived words, not raw deterministic database facts; the screen currently hides that distinction.

**A6 — FINDING (MAJOR).** Important required negative cases are absent: no real later extension re-injects a stamped carrier; no forged `nana-block` ledger entry is rejected; no empty-tools manifest proves shell tools remain absent; no concurrent session-spawn race; no failed/timed/two-dialog gate case; and no real malformed basketball tool result traverses the full chain. The stage test substitutes an unstamped fixture rather than exercising validation (`apps/desk/test/stage-page.e2e.mjs:37-38,64-65,112-116`). The argv assertion tests the spawning implementation rather than the active-tool invariant (`apps/desk/test/app-listener.test.mjs:102-107`), and “no temp file left behind” does not establish atomic write behavior (`apps/desk/test/app-listener.test.mjs:113-114`).

**A7 — FINDING (MAJOR).** The incremental cursor earns complexity while being incorrect. After initial load, `syncEntries` fetches entries since the cursor but never applies them; it only advances the cursor, so blocks missed during an SSE disconnect are permanently omitted until a full page reload (`apps/desk/public/stage/stage.js:269-279`). A delta alone also lacks the ancestors required for branch reduction. Slice 1 should simply fetch and reduce the complete ledger on `desk_hello`, `tool_execution_end`, and `agent_settled`; session sizes do not justify a broken incremental path.

**VERDICT: REWORK**

1. Make ledger/live consumption authoritative: validate every consumed block, strictly verify provenance, remove trust in live carriers, and define or enforce an ownership boundary for `nana-block` entries.
2. Serialize per-app spawn and manifest write-back; reject empty tool allowlists or explicitly pass `--no-tools`.
3. Keep gates mounted until a successful response; reconcile failures, timeouts, resolution, and child exit, with two-dialog tests.
4. Distinguish raw data from analyst/model-derived report and dossier content on screen.
5. Replace cursor deltas with full active-branch replay and active-branch-only drawer history.
6. Add the missing adversarial lifecycle, gate, tool-allowlist, and carrier-injection tests.
