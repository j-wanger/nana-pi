Classify each finding MUST, SHOULD or NOTE. A MUST names a realistic input under the brief's threat model and a consequence that matters: data lost or corrupted, a security or review boundary bypassed in practice, wrong output someone acts on, a broken install or hook, or a regression of behaviour main has today. If you cannot name both, the finding is a SHOULD or NOTE. Contrived inputs, rare edge cases, wording, citation bookkeeping and gaps in test evidence are SHOULD or NOTE.
A confirmation round reviews only the change since the revision the brief names as the last round, and whether the named MUSTs are closed.
The last line of your answer is exactly `VERDICT: LAND` when no MUST stands, or `VERDICT: SEND-BACK` when one does, optionally followed by a score such as 9/10. Do not use LAND-WITH-FIXES. Write no other verdict line, except an identical one on the first line when the brief asks for it.
